Visual mode tip
Visual mode includes the anchor and cursor characters. w lands on the next word’s first character; e lands at a word end. Motions remain exact across paragraphs while the snapshot is valid. V selects whole display lines. Use gg for the first line; g now waits for a second command key.

About . and registers
. repeats deletes/changes/paste, but can't retype text you typed during an insert-mode change (e.g. after cw you'll need to type the replacement again). Yank and r are never repeated by .

"{reg}, e.g. "ayy then "ap, uses a named register instead of the clipboard, saving/restoring your real clipboard around the command. Plain y still goes straight to the clipboard; plain d/c now land in a dedicated cut register ("-) instead, so deleting doesn't clobber your clipboard -- "-p pastes it back. Uppercase ("A) appends; "_ discards (black hole). Registers store plain text; see the README for clipboard limitations.

Search and g motions

/text + Enter searches forward; ?text searches backward. Queries are literal, with \c / \C case flags and \n for a paragraph break.

n / N repeat; * / # search the word under the cursor. Searches wrap. d/hi + Enter deletes up to the next “hi”, excluding the match; c/y and counts work too.

ge / gE move to the previous word/WORD end; g_ goes to the last nonblank. gj / gk use native display lines. 3gg / 3G go to the third paragraph line.
